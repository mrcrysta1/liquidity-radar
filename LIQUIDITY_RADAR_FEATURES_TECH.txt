SECTION 2: ALGORITHMS / TECHNIQUES USED (TECHNICALLY)
--------------------------------------------------------------

1. RSI (Relative Strength Index) - Wilder's smoothing
   rsi = 100 - 100/(1 + avgGain/avgLoss)

2. MACD - EMA(12) - EMA(26), signal = EMA(9) of line

3. EMA (Exponential Moving Average)
   ema = price*k + prev*(1-k), k = 2/(period+1)

4. Bollinger Bands - mean +/- 2*stddev (20 periods)
   %B = (last - lower)/(upper - lower) * 100

5. ATR (Average True Range) - true range over 14 bars

6. Linear Regression (least squares) for the ML Forecast
   slope/intercept = (n*Sxy - Sx*Sy)/(n*Sxx - Sx^2)
   Projection: pred = last + slope * horizonSteps * damping

7. Volatility scaling: realized per-bar std deviation,
   bands = price * sd * sqrt(horizon) * 1.28 (80% CI)

8. Composite AI Score (-100..+100):
   weighted blend of RSI, MACD hist, EMA distance,
   Bollinger %B, volume trend, price-from-mean

9. Logistic / Sigmoid for direction probability:
   P(up) = 1 / (1 + exp(-score/45))

10. Multi-timeframe weighted ensemble:
    weightedScore = SUM(tf.score * tf.weight) / SUM(tf.weight)

11. Online auto-learning (gradient-free adaptive weights):
    - outcome key -> weight-key mapping (master_BUY -> master)
    - hitRate > 0.6  => increase weight (max clamp)
    - hitRate < 0.42 => decrease weight (min clamp)
    - weights persisted in localStorage (lr-modelW)
    - accuracy tracker persisted (lr-patternHist)

12. Whale flow imbalance:
    imb = (buyUsd - sellUsd)/(buyUsd + sellUsd)

13. Pattern detection:
    - RSI divergence (price new high vs RSI lower)
    - MACD crossovers
    - Bollinger band touch
    - volume spikes
    - swing support/resistance proximity

14. Liquidation zone estimation from OI + ATR:
    longZone = support - 1.1*ATR .. support - 0.3*ATR

15. Data structures: hash maps (tickers), promise.all for
    parallel scanning, localStorage for persistence

NOTE: The model uses a lightweight, deterministic
      adaptive-weighted approach (not a hand-written
      backprop neural net) for reliability/speed.
