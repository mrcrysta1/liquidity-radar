# Liquidity Radar (React + Vite + TypeScript)

Phase 1 migration of the single-file `../index.html` ("Liquidity Radar v5.0 —
Crypto Microstructure Terminal") into a React + Vite + TypeScript application,
with Tailwind CSS, ESLint and Prettier.

**Goal: preserve 100% of existing functionality — migrate, don't rewrite.**

## Architecture

Three layers, mirroring the vanilla app exactly:

| Layer      | Path                           | What it is                                                                                                                                                                 |
| ---------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| View shell | `src/components/Shell.tsx`     | Mechanical 1:1 port of the original body HTML (every `id`/class preserved). Generated by `scripts/html2jsx.cjs` from `../index.html` — do not hand-edit.                   |
| Engine     | `src/engine/app.ts`            | Faithful TS port of the original inline `<script>` (Binance REST/WS, signals, AI, news, calendar, alerts, themes…). Logic untouched; `@ts-nocheck` is a transitional seam. |
| Mount      | `src/App.tsx` + `src/main.tsx` | React root. The engine is `import()`ed inside `useEffect` so it evaluates only after the DOM shell exists — preserving the vanilla script's end-of-`<body>` boot order.    |

- Original stylesheet: `src/index.css` (verbatim) + Tailwind v4 theme/utilities (preflight disabled so visuals are unchanged).
- `lightweight-charts@4.1.3` is now an npm dependency (was a CDN `<script>`); the engine aliases it via `import * as LightweightCharts`.
- Classic-script globals (`switchTab`, `closeModal`, …) that inline `onclick`/generated HTML rely on are explicitly re-exposed onto `window` inside `initApp()`.

## Commands

```bash
npm install        # install deps
npm run dev        # Vite dev server
npm run build      # tsc -b && vite build
npm run preview    # serve the production build
npm run lint       # ESLint (flat config; engine file is intentionally ignored)
npm run format     # Prettier --write
npm run smoke      # headless-Chrome parity smoke test (needs `npm run build` first)
```

`npm run smoke` serves `dist/` and asserts the engine boots: tabs render,
Binance WebSocket streams go live (`LIVE · N STREAMS`), the chart canvas
mounts, window globals are exposed, tab switching works, and no JS errors
leak to the console. External-feed noise (faireconomy/xoomar CORS or rate
limits) is non-fatal — those APIs run on their known fallback paths.

## Regenerating generated files

```bash
node scripts/html2jsx.cjs   # regenerate src/components/Shell.tsx from ../index.html
```

## Phase 2+ (incremental React-ification)

Ship a working, behavior-identical app first; then convert one tab at a time
from the engine's imperative DOM code into declarative React components,
removing the `@ts-nocheck` seam section by section. Each conversion is
verified against `npm run smoke` for parity.
