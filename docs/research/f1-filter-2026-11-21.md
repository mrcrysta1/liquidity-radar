# ML filter on F1's entries (2026-11-21)

**Findings (written after the run; numbers below are the script's output, `npm run f1-filter`).**

- Not passed by the rules fixed before the run (2 of 5 checks failed), so it
  does not go to the bot. But it is the best ML result so far:
- **2025–2026 (holdout, unseen):** the logistic filter took 48% of F1's
  trades. Taken +0.134R per trade vs F1 alone +0.033R; skipped −0.058R;
  total 61R vs 32R for F1 alone with about half the trades; return over
  drawdown 1.86 vs 0.48. C6 did almost the same (+0.120 / −0.058).
- **Why it fails:** the gap taken − skipped (+0.19R) has a 95% range from
  −0.20 to +0.58, so it may be luck; and in 2019–2024 the skipped trades
  still earned +0.142R, so the filter threw away profitable trades (total
  434R → 253R) in F1's good years.
- **Reading:** in F1's strong years every breakout pays and a filter only
  costs profit; in weak years (2025–2026) both filters avoided the losers.
  Two independent filters agreeing on 2025–2026 is encouraging but is one
  period. More data (paper trading) is the way to prove or reject it.

## Limits

- F1 trades are few per half-year; ranges are wide. The taken − skipped range treats the two groups as independent (they share market days), so it is approximate.
- Survivorship (today's 24 coins); funding before ~2019-09 is a default rate; 4h candles.
- C6's holdout is not independent evidence (C6 was designed after 2025 was seen).
